# 🧳 여행 유튜브 벤치마킹·분석 대시보드

구독 1만이라는 1차 목표를 위해, **작은 채널인데 조회수가 터진 영상**과 **꾸준히 잘 되는 숨은 고수 채널**을 모아 공부하는 도구예요.
내 Mac에서 돌아가고, AI 분석은 **내 Claude 구독**으로 해요 (API 키 비용 없음).

- **채널 발굴**: 여행 키워드 탐색, 블링·녹스 같은 사이트에서 찾은 URL 한 번에 가져오기, 추천 채널 확장
- **숨은 고수 찾기**: 구독 1만 미만인데 1~2주에 1개씩 꾸준히 올리고, 조회수 중앙값이 1만 이상인 채널
- **돌파 영상 찾기**: 조회수 ÷ 구독자 = 돌파 지수. 구독 100만 채널의 10만 조회(0.1배)가 아니라 구독 5천 채널의 10만 조회(20배)를 찾아요
- **AI 분석**: 기획 장치, 매 영상 반복되는 시그니처(예: 숙소마다 하는 "냄새 체크"), 정보 밀도, 제목·썸네일·훅, 댓글 속 시청자 니즈
- **성장 추적**: 채널별 터닝포인트 영상, 구독 1만을 넘긴 채널(관문 돌파) 사례 연구

여행 브이로그뿐 아니라 **정보성 여행 · 숙소/시설 리뷰 · 이색 장소 탐방 · 로컬 맛집/시장 탐방**까지 5가지 유형을 모아요.

## 1. 먼저 데모로 둘러보기 (설치 5분, 키 필요 없음)

```bash
cd travel-ai
DEMO=1 bash start.command
```
가상 채널("샘플 ○○")로 모든 화면을 볼 수 있어요. 실제 데이터와는 따로 저장돼요.

## 2. 한 줄 설치 (Mac, 추천)

**터미널**(응용 프로그램 → 유틸리티 → 터미널)을 열고 아래 한 줄을 붙여넣은 뒤 엔터:
```bash
curl -fsSL https://raw.githubusercontent.com/joker3036/-/refs/heads/claude/travel-youtube-ai-content-z73yyg/travel-ai/install.sh | bash
```
자동으로 해 주는 것
- 코드를 `~/travel-ai` 폴더에 받기 (다시 실행하면 최신 코드로 바꾸고, 모은 데이터와 키는 그대로)
- Python 3.12와 필요한 패키지 준비 (Python을 따로 설치할 필요 없음, 관리자 비밀번호 불필요)
- Claude Code 설치 → 로그인 안 되어 있으면 브라우저 로그인 창 열기
- Google Cloud Console을 열어 두고, 만든 YouTube API 키를 붙여넣으면 확인 후 저장
- 바탕화면에 **'여행 벤치마킹'** 실행 아이콘 만들기 (다음부터는 더블클릭)
- 대시보드 열기

직접 해야 하는 것은 두 가지뿐이에요: **Claude 로그인 버튼 누르기**, **Google Cloud Console에서 API 키 만들기**(아래 ③ 참고).

## 3. 직접 설치 (한 줄 설치가 안 될 때)

필요한 것: macOS 13 이상, Claude **Pro 또는 Max** 구독 (무료 플랜은 Claude Code를 쓸 수 없어요)

### ① 코드 받기
[이 브랜치 ZIP 받기](https://github.com/joker3036/-/archive/refs/heads/claude/travel-youtube-ai-content-z73yyg.zip)를 눌러 내려받고 압축을 푸세요 (GitHub에 로그인한 브라우저에서).
압축을 푼 폴더 안에 `travel-ai` 폴더가 있어요. 찾기 쉬운 곳(예: `문서`)으로 옮겨 두세요.

### ② Python 3.10 이상
[python.org/downloads](https://www.python.org/downloads/)에서 macOS용 최신 버전을 설치하세요.
터미널(`응용 프로그램 → 유틸리티 → 터미널`)에서 `python3 --version`을 쳤을 때 3.10 이상이면 OK.

### ③ YouTube Data API 키 (무료)
1. [Google Cloud Console](https://console.cloud.google.com/)에 로그인 → 위쪽에서 **새 프로젝트** 만들기
2. **API 및 서비스 → 라이브러리**에서 `YouTube Data API v3` 검색 → **사용**
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**
4. (권장) 만든 키의 **API 제한사항**을 `YouTube Data API v3`로 제한
5. 키를 복사해 두세요. 대시보드를 연 뒤 **설정** 페이지에 붙여넣어요 (또는 `travel-ai/.env` 파일에 `YOUTUBE_API_KEY=키`)

### ④ Claude Code 설치·로그인 (AI 분석용)
터미널에 아래를 붙여넣고 엔터:
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
끝나면 **새 터미널 창**을 열고 `claude`를 실행해서, 브라우저에 뜨는 안내대로 **Claude 계정(구독)으로 로그인**하세요. 로그인되면 `/exit`로 나오면 돼요.
대시보드는 이 로그인을 그대로 써서 `claude -p` 명령으로 분석을 돌려요. ([공식 설치 안내](https://code.claude.com/docs/en/setup))

> ⚠️ 이 방식은 **내 PC에서 내가 쓰는 용도**예요. 이 도구를 다른 사람에게 서비스로 제공하려면 Anthropic 정책상 API 키 방식으로 바꿔야 해요.

### ⑤ 실행
터미널에서 `cd ` (cd 다음 한 칸 띄우기)를 입력하고, Finder의 `travel-ai` 폴더를 터미널 창으로 **끌어다 놓은 뒤** 엔터. 그다음:
```bash

```
- 처음 한 번은 패키지 설치로 1~2분 걸리고, 브라우저에 대시보드가 자동으로 열려요 (안 열리면 터미널에 나온 `http://localhost:8501` 주소를 여세요)
- 끝낼 때는 터미널에서 `Control + C`
- 다음부터는 같은 방법으로 `bash start.command`만 실행하면 돼요
- `start.command`를 Finder에서 더블클릭해도 되지만, 인터넷에서 받은 파일이라 macOS가 막을 수 있어요. 그럴 땐 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 **"그래도 열기"**를 누르세요

## 4. 사용 흐름

1. **🔎 채널 발굴**
   - **URL·CSV 가져오기**: 롤모델(곽튜브 등)을 ⭐ 롤모델로 등록하고, 블링·녹스에서 필터로 찾은 1만 미만 여행 채널 주소를 붙여넣기
   - **키워드 탐색**: "영월 뚜벅이", "여인숙 탐방"처럼 좁은 키워드로 작은 채널을 찾아요. 한 번에 10~30개씩, 여러 번 돌리면 채널 풀이 쌓여요
   - **추천 채널 확장**: 관심 채널이 채널 페이지에 걸어둔 추천 채널을 스캔
2. **📌 관심 채널**: 숨은 고수·근접 후보를 📌로 고정 → **주 1회 "전체 갱신"** → 구독자 추이와 관문 돌파가 쌓여요. "전체 업로드 수집"을 누르면 성장 타임라인과 터닝포인트가 보여요
3. **🔥 떡상 영상**: 산점도에서 기준선(조회수 = 구독자 × 10)보다 위에 있는 점이 작은 채널의 돌파 영상. **돌파 영상 자동 선택 → 대기열 실행**으로 AI 분석
4. **🎬 영상 상세**: 분석 결과(잘 된 이유, 내 채널에 적용할 점, 시그니처, 훅, 시청자 반응) 확인
5. **📊 패턴 분석**: 기획 장치·제목 장치·유형·길이·요일별로 어떤 게 돌파 지수가 높았는지

## 5. 지표 설명

| 지표 | 계산 | 의미 |
|---|---|---|
| 돌파 지수 | 조회수 ÷ 구독자 | 채널 크기에 비해 얼마나 멀리 퍼졌나 |
| 채널 평소 대비 (떡상 점수) | 조회수 ÷ 그 채널 최근 롱폼 30개 조회수 중앙값 | 그 채널 평소보다 얼마나 잘 됐나 |
| 조회수 중앙값 | 최근 롱폼 10개를 줄 세운 가운데 값 | 영상 하나만 터져도 올라가는 평균과 달리 "꾸준함"을 보여줌 |
| 롱테일 지수 | 업로드 30일 이후 일평균 증가 ÷ 전체 일평균 | 1에 가까우면 검색으로 오래 조회되는 영상 (갱신 2번 이상 필요) |
| 터닝포인트 | 직전 10개 중앙값의 3배 이상 나온 첫 영상 | 채널이 뜨기 시작한 지점, 전후로 유형이 바뀌었는지도 표시 |

**채널 그룹** (기준은 설정에서 바꿀 수 있어요, 모두 롱폼 기준)
- 🎯 **숨은 고수**: 구독 1만 미만 · 최근 90일 롱폼 6개 이상 · 업로드 간격 중앙값 14일 이하 · 최대 공백 28일 이하 · 마지막 업로드 21일 이내 · 조회수 중앙값 1만 이상 · 여행 관련 영상 50% 이상
- 🌱 **근접 후보**: 위 조건 중 딱 하나만 못 채운 채널
- 🎓 **관문 돌파**: 추적하던 채널이 구독 1만을 넘으면 자동 표시
- ⭐ **롤모델**: 직접 등록 (구독자 수 상관없음)

## 6. 채널을 찾는 방법과 한도

YouTube API에는 "구독자 1만 미만 여행 채널 검색" 기능이 없어서, **영상을 검색해 올린 채널을 거꾸로 찾는 방식**이에요.

| 방법 | 한도 | 비고 |
|---|---|---|
| 공식 검색 | 하루 100회 | 안정적 |
| 비공식 검색 (scrapetube) | 없음 | 무료. 단, YouTube 약관상 자동화된 접근에 해당할 수 있고 언제든 막힐 수 있어요. 막히면 자동으로 공식 검색으로 바꿔요. **설정**에서 끌 수 있어요 |
| 채널·영상 정보 조회 | 하루 10,000 유닛 | 채널 1개 스캔 ≈ 2~3유닛 → 하루 1,000~2,000개 채널 검사 가능 |
| 외부 사이트 | - | [블링](https://vling.net) · [플레이보드](https://playboard.co) · [녹스인플루언서](https://kr.noxinfluencer.com) · [뷰트랩](https://app.viewtrap.com)(유료)에서 필터로 찾고 URL/CSV 가져오기 |

구독자·조회수 같은 숫자는 어떤 방법으로 찾았든 항상 **공식 API**로 가져와요. 할당량은 태평양 시간 자정(한국 오후 4~5시)에 초기화돼요.

## 7. 터미널 명령 (선택)

```bash
cd travel-ai && source .venv/bin/activate   # start.command를 한 번 실행한 뒤
python collect.py discover --keywords 20              # 키워드 탐색
python collect.py discover --kinds stay explore       # 숙소 리뷰·이색 탐방 키워드만
python collect.py import channels.csv --role-model    # URL 목록·CSV 가져오기
python collect.py refresh                             # 관심 채널 갱신
python collect.py analyze --auto 10                   # 돌파 영상 10개 AI 분석
python -m pytest tests                                # 테스트
```

## 8. 데이터와 정책
- 모든 데이터는 `travel-ai/data/`(SQLite)에 저장되고 git에는 올라가지 않아요
- YouTube API 정책에 맞춰 **30일 넘게 갱신 안 된 채널 데이터는 자동 정리**해요 (📌 관심·⭐ 롤모델 채널은 제외 — 주기적으로 갱신하세요)
- 다른 채널 자막은 공식 API로 받을 수 없어서 `youtube-transcript-api`(비공식)를 써요. 집 인터넷에서는 잘 되고, 자막이 없으면 제목·설명·댓글로만 분석해요
- AI 분석 결과는 영상마다 한 번만 만들고 저장해요. 구독 사용 한도에 걸리면 대기열에 남겨 두고 다음에 이어서 해요

## 9. 문제 해결
- **"YouTube API 키가 필요해요"** → 설정 페이지에서 키 입력 후 "키 확인"
- **"비공식 검색 실패 → 공식 검색으로 전환"** → YouTube 구조 변경이나 차단. `pip install -U scrapetube` 후 다시 시도하거나 설정에서 끄세요
- **"Claude Code 로그인이 필요합니다"** → 터미널에서 `claude` 실행 후 로그인. 설정 페이지의 "Claude 연결 테스트"로 확인
- **"사용 한도에 걸려 멈췄습니다"** → 구독 사용 한도예요. 몇 시간 뒤 "대기열 실행"을 다시 누르면 이어서 분석해요
